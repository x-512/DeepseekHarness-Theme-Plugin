DeepSeek Harness Chrome App Mode Portable - Lulu Theme Edition

This package already includes the Lulu custom image/video theme plugin.

Theme source reference: https://haowallpaper.com/homeView

Requirements
- Windows 10 or Windows 11 x64
- Google Chrome installed
- Internet access for model providers and optional mobile Quick Tunnel

Quick Start
1. Extract the entire ZIP to a stable folder. Do not run it from inside the ZIP.
2. Double-click "启动DeepSeekHarness.cmd".
3. Open the Harness web UI. The "切换主题" button should appear automatically.

Optional Desktop Shortcut
- Double-click "安装桌面快捷方式.cmd" if you want desktop shortcuts.
- Use "DeepSeek Harness 手机配对" when an Android device needs pairing.

Theme Plugin
- The theme plugin is bundled under profile-template\web\plugins\dsh-theme-lulu.
- It is mounted by profile-template\web\cordis.patch.yml.
- You can switch built-in themes, upload PNG/JPEG/WebP/GIF images, and upload MP4/WebM video themes.

Desktop behavior
- The visible window is Chrome App Mode: no address bar, tabs, or browser buttons.
- No custom EXE is used and no private code-signing certificate is required.
- The signed Google Chrome executable remains unchanged.

Local data
- Runtime data is created under %LOCALAPPDATA%\DeepSeekHarnessPortable.
- The default workspace is Documents\DeepSeekHarnessWorkspace.
- The ZIP contains no API keys, credentials, sessions, workspaces, logs, browser profiles, custom theme uploads, or pairing state.

Important
- This package does not include model-provider credentials. Configure them on the receiving computer.
- Windows may mark a downloaded ZIP as coming from the Internet. If scripts are blocked, open ZIP Properties, select Unblock, then extract it again.
- Cloudflare Quick Tunnel addresses can change after restart and have no uptime guarantee.
