# DeepSeek Harness 主题插件便携版

这个仓库的 GitHub `Code -> Download ZIP` 下载内容就是完整的 DeepSeek Harness 便携版，主题插件已经内置。

主题来源参考: https://haowallpaper.com/homeView

## 使用

1. 点击 GitHub 页面绿色 `Code` 按钮。
2. 点击 `Download ZIP`。
3. 解压整个 ZIP，不要在压缩包内部运行。
4. 双击根目录中的 `启动DeepSeekHarness.cmd`。
5. 打开 Harness 后，右上角会出现 `切换主题`。

也可以双击 `安装桌面快捷方式.cmd` 创建桌面启动入口。

## 根目录

```text
启动DeepSeekHarness.cmd
安装桌面快捷方式.cmd
app/
launcher/
mobile/
profile-template/
runtime/
README.txt
VERSION.txt
```

主题插件位于:

```text
profile-template/web/plugins/dsh-theme-lulu
```

已移除“主题静态”按钮，主题只保留动态模式。

要求 Windows 10/11 x64，并安装 Google Chrome。模型服务凭据需要在用户自己的环境中配置。
